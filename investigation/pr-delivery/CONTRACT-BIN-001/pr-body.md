When rustc omits `--crate-type`, [is_user_facing_executable](https://github.com/kunobi-ninja/kache/blob/4ee0f9e2b9673aa16f29c9c7e39bf8d0152671d9/src/args.rs#L754-L756) misses the default binary, so `cache_executables=false` bypasses the configured fallback. Treat the omitted type as user-facing to preserve that fallback contract. Extended `user_facing_executable_preserves_configured_fallback_contract` covers explicit and implicit binaries; `just check` passes.
