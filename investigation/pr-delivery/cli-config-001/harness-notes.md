The first full gate used a temporary global HOME and TMPDIR and failed the unchanged macOS sandbox preflight integration test. That log is retained as gate-initial.log. The same test failed with temporary HOME alone (sandbox-home-only.log), and temporary TMPDIR alone (sandbox-tmp-only.log), but passed with the normal toolchain environment (sandbox-default-env.log). No fallback source or assertions were changed.

The final gate retains the normal toolchain HOME/TMPDIR and unsets ambient KACHE_RUNTIME_DIR. CLI commands integration fixtures already supply a disposable HOME, CARGO_HOME, XDG_CONFIG_HOME, config path and cache to each command. The external Cargo proof additionally uses short lexical /tmp fixtures, with host configuration explicitly disabled. These fixture homes/configs/caches are separate from the toolchain environment.
