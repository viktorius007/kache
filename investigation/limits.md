Anonymous signing and fixture configuration are test conveniences; production supports the same S3 transport. The copied crate root only adds the investigation module and reads the original module tree through symlinks.

The server provides valid cache packs produced by Store/RemoteLayout. For large objects it sends real headers plus the first 1024 bytes, then deliberately holds the tail until cleanup. This tests request occupancy, not achievable S3 throughput or disk bandwidth. Direct HEAD controls bypass the daemon pool and measure endpoint responsiveness only; they do not prove daemon HEAD latency. The one-free-permit small restore control proves the small object is present and valid.

One-second demand requests are supported in production when a client has remote_restore_timeout_secs=1 while its daemon has a larger setting; the request carries its own stricter budget. Uniform default clients have a three-second ceiling. Report these cases separately. All overload claims are bounded by the demand ceiling and the breaker's configured cooldown. No OOM, artifact corruption, indefinite starvation or generalized performance conclusion is inferred.
